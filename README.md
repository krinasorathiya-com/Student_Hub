# StudentHub Portal

## Project Overview
StudentHub is a web-based student management portal developed using PHP, MySQL, HTML, CSS and JavaScript.

## Technologies Used
- HTML5
- CSS3
- Bootstrap
- JavaScript
- PHP
- MySQL
- XAMPP

## Features
- Student Registration and Login
- Student Dashboard
- Event Management
- Event Registration
- Admin Login
- Admin Dashboard
- Role-Based Access
- Audit Logs

## Installation Steps
1. Install XAMPP.
2. Copy Student_Hub folder into htdocs.
3. Start Apache and MySQL.
4. Open phpMyAdmin.
5. Import studenthub.sql.
6. Configure config/db.php.
7. Open http://localhost/xampp/Student_Hub/
